Implement **Module 2 — ML Prediction Engine** for our existing **GridMind** project.

### Goal

Build forecasting for:

* ⚡ Demand
* ☀️ Solar generation
* 🌬️ Wind generation

using the **actual historical data from Module 1 / existing datasets**.

### Requirements

1. **Inspect the repo first**

   * Understand Module 1 data sources, schemas, storage, and existing conventions.
   * Reuse existing infrastructure; don't create duplicates.

2. **Feature Engineering**

   * Time features, lag features, rolling statistics.
   * Weather features if available.
   * Prevent future-data leakage.

3. **Models**

   * Use **XGBoost regression** for Demand, Solar, and Wind.
   * Keep it simple and hackathon-friendly.
   * No LSTM, Transformers, RL, GNN, cloud services, MLflow, or LLM-based forecasting.

4. **Evaluation**

   * Chronological **70/15/15 train/validation/test split**.
   * Evaluate on unseen test data using **MAE, RMSE, MAPE** where appropriate.
   * Never fabricate metrics.

5. **Uncertainty**

   * Use validation residuals to generate prediction intervals.
   * Return `prediction`, `lower`, `upper`, and `confidence`.

6. **Storage**

   * Save trained models using the existing convention, preferably `data_storage/trained_models/`.

7. **API**
   Implement/reuse:

   * `/api/forecast/demand`
   * `/api/forecast/solar`
   * `/api/forecast/wind`
   * `/api/predictions`

   Keep outputs structured for the future **Risk & Forecast Agent**.

8. **Testing**
   Add tests for feature engineering, all models, uncertainty, service/API, and edge cases.

9. **Endpoint Verification — REQUIRED**
   After implementation:

   * Start the FastAPI backend.
   * Verify **every Module 2 endpoint actually responds successfully**.
   * Test valid and invalid inputs.
   * Confirm response schemas and prediction values are correct/non-empty.
   * Confirm models load correctly during API inference.
   * Fix any endpoint, routing, schema, import, or integration errors found.
   * Do not consider Module 2 complete until all endpoints have been tested successfully.

### Integration

`Module 1 data → Feature Engineering → ML Models → Predictions + Uncertainty → Risk & Forecast Agent`

Do NOT implement agents, market, simulation, or Safety Layer inside Module 2.

### Final Report

After completing everything, report:

* Files changed
* Dataset used
* Features used
* Train/validation/test split
* Model metrics
* Uncertainty method
* Tests passed
* Endpoint test results
* Any remaining limitations

**Most important:** verify predictions against unseen real historical data and verify that **all API endpoints work end-to-end**. Do not claim success merely because the code runs.
